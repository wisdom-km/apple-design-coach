# 功能落位剧本（Placement Playbook）

在写输出骨架的「功能落位 / IA」与「UI 结构」前加载本文件。  
原则判断见 `eight-principles.md`；平台边界见 `surfaces.md`。

落位目标：让用户识别当前位置、找到主要操作并完成任务，且位置符合该表面惯例。完成时间和步数依据业务与可用性测试确定；本文件是设计启发，不是 Apple 的通用硬阈值。

---

## 通用落位流程

1. 确定本次关注的主任务，保留需求中的次要任务，不按固定数量删除能力
2. 标频率：高频 / 中频 / 低频 / 危险  
3. 按表面选 **导航壳**（下表）  
4. 按频率与语义落位：主任务直接可达；配置进入设置，业务操作保留在相关上下文；风险操作与普通操作可区分，按后果选择撤销或确认。未知频率先标假设
5. 画出区域：导航 / 主内容 / 主操作 / 辅助 / 状态  
6. 检查 Agency（撤销）与 Responsibility（权限时机）

## 按表面：导航壳与落点

### iOS

| 要素 | 建议 |
|------|------|
| 一级导航 | 多个同级顶级目的地可用 Tab；单任务工具不必强加 Tab；数据型可用列表+详情。数量按信息架构与系统能力确定 |
| 主操作 | 导航栏尾部按钮；或主内容区明确 CTA；编辑态用上下文工具栏 |
| 返回/层级 | 推入导航栈；模态/Sheet 用于短时分支任务 |
| 搜索 | 导航区域或列表顶；结果页保持可撤销 |
| 设置 | 应用内「设置」入口（常在 Tab 或个人资料）；系统级能力才进系统设置 |
| 危险操作 | 破坏项需区分强调；低风险且可恢复时提供撤销，重大或不可逆后果前确认 |

**避免：** Tab 塞满低频项；用模态做主流程导致无法返回上下文。

### iPadOS

| 要素 | 建议 |
|------|------|
| 一级导航 | 侧边栏 + 内容列；宽屏多栏（列表 | 详情 | 检视器） |
| 主操作 | 工具栏；多选后批量栏 |
| 指针/键盘 | 提供指向目标与快捷键，不与触控互斥 |
| 多任务 | 关键流程在分屏/Stage Manager 下仍可读 |
| 设置 | 侧边栏末端或工具栏齿轮；复杂设置用独立设置列 |

**避免：** 简单放大 iPhone 单栏；忽略多选与拖放机会。

### macOS

| 要素 | 建议 |
|------|------|
| 一级导航 | 侧边栏分区；或工具栏分段 |
| 命令发现 | 菜单栏提供完整命令；工具栏放高频；快捷键服务专家 |
| 主操作 | 工具栏主按钮；面板内主 CTA |
| 多窗口 | 文档型可多窗；工具型注意单例面板 |
| 设置 | 标准设置窗口 + 侧边栏分类 |
| 右键 | 上下文菜单复现选区相关命令 |

**避免：** 无菜单等价物的「仅手势」；把移动端汉堡菜单当 Mac 主导航。

### Windows desktop

| 要素 | 建议 |
|------|------|
| 一级导航 | NavigationView / 枢纽；或顶部功能区（文档重编辑类） |
| 主操作 | 命令栏/工具栏左侧主命令；页面内主按钮 |
| 系统集成 | 标题栏、跳转列表、系统主题（亮暗）诚实响应 |
| 设置 | 应用内设置页；遵循 WinUI/Fluent 信息层级 |
| 上下文 | 右键菜单；加速键 |

**避免：** 假 iOS Tab + 大卡片堆；忽略键盘与多窗口。  
**声明：** 精神借用，非 HIG 合规（见 `surfaces.md` 规则 2）。

### Web

沿用站点导航、链接、浏览器返回与历史；表单用语义化输入和按钮，保留可见焦点。响应式布局根据可用空间与任务调整，不因为在 Mac/Windows 浏览器运行就更换为原生 OS 控件。

业务操作留在相应内容附近，设置只收纳配置。优先复用项目组件与 tokens；不要为“Apple 风格”重写框架。错误与完成反馈参考 [WAI User notifications](https://www.w3.org/WAI/tutorials/forms/notifications/)。

### Browser extension

| 要素 | 建议 |
|------|------|
| 弹窗（popup） | **单一主任务**；标题 + 简短状态 + 1 个主按钮 + 必要次要链接 |
| 侧栏（side panel） | 允许稍长工作流；仍要分段与清晰主 CTA |
| 选项页（options） | 权限说明、账户、默认值、低频配置 |
| 内容脚本 UI | 最小覆盖；不阻挡宿主关键控件；易关闭 |
| 权限 | 可选权限在用户点击需要它的动作时请求 |

**避免：** 弹窗变「迷你 App 厨房水槽」；安装时申请全部主机权限。  
**声明：** 精神借用，非 HIG 合规。

Chrome popup 在焦点移到外部时会关闭，见 [官方说明](https://developer.chrome.com/docs/extensions/develop/ui/add-popup)。需要切换标签页的长任务应考虑侧栏/独立页面和持久草稿；仅拉高弹窗不能解决生命周期问题。按目标浏览器与版本核实支持，不假定所有扩展环境都有相同 side panel API。

## 功能类型 → 落点速查

| 功能类型 | iOS | iPadOS | macOS | Windows | Extension |
|----------|-----|--------|-------|---------|-----------|
| 核心每日任务 | Tab 或首页主 CTA | 侧边栏首项 + 多栏 | 侧边栏首项 + 工具栏 | 导航首项 + 命令栏 | 弹窗主 CTA |
| 创建/新建 | 导航栏 + 或 FAB 慎用 | 工具栏 + | 工具栏 + / ⌘N / 菜单文件 | 命令栏「新建」 | 弹窗主按钮；复杂创建进选项页/新标签 |
| 搜索 | 列表顶/导航 | 工具栏搜索 | 工具栏搜索框 | 命令栏搜索 | 弹窗内仅短过滤；全量搜索进整页 |
| 通知/收件箱 | 专 Tab 或首页模块 | 侧边栏 + 徽章 | 侧边栏/菜单 | 导航项徽章 | 徽章 + 弹窗列表 |
| 个人资料/账户 | Tab 或设置顶 | 侧边栏底 | 设置/菜单账户 | 设置/账户菜单 | 选项页 |
| 设置 | 应用内设置层级 | 侧边栏/独立列 | 设置窗口 | 设置页 | 选项页 |
| 权限相关能力 | 首次用到时请求 | 同左 | 同左 + 系统偏好说明 | 同左 + 系统隐私 | 可选权限 + 选项页说明 |
| 危险/删除 | 区分后果；可靠撤销或必要确认 | 同左 | 上下文命令；撤销或确认 | 同左 | 就近说明后果；恢复或确认 |

## 落位验收（输出前自检）

- [ ] 高频任务一级可达；危险与高频不同形  
- [ ] 设置可发现且不抢主路径；业务操作没有仅因低频被误归入设置
- [ ] 多表面差表已写（若适用），非复制同一线框  
- [ ] 扩展弹窗无「厨房水槽」  
- [ ] Windows/扩展有非 HIG 合规声明
