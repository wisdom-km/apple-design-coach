# 视觉方向（具体，但不编造规范数字）

写「UI 结构」时一起写。用户没要可视草稿时，也要给出能执行的视觉方向。用户要了草稿时，草稿必须遵守这里的方向，而不是另起一套装饰。

官方数字只在 `source-provenance.md` 有出处时使用，并写出来源。项目自己定的字号、间距、色值，标明「项目决定」或「示例决定」。不要把示例决定说成 HIG、Material 或 Fluent 的测量值。

---

## 方向要成套

一次只定一套，并说明它如何服务主任务：

1. **字体角色**：该平台的系统字体优先。至少区分正文、次要说明、主结果或标题。用字重和字号建立层级，不靠把每块都放进卡片。
2. **间距节奏**：选定一个重复的间距（常见是 4 或 8 的倍数）。这是项目决定，除非某条官方指南明确写了这个数。
3. **密度**：手机留出触控间距；桌面可以更密，但层级仍要一眼可读；扩展弹窗最紧，只留主任务。密度跟着会话长度走，不跟着「看起来高级」走。
4. **颜色角色**：背景、表面、主文字、次文字、一个强调色、一个危险色。强调色只用在主操作和当前选中。危险操作不与主按钮同形同色。不要只靠颜色区分状态。
5. **层级**：最大的、最对比的、最靠近主路径的，是主任务。其余降级，而不是等权排列。

避免这些没有任务理由的套路：等大卡片叠卡片、每块一个状态标签、渐变色块加口号、所有按钮一样重、首屏堆满字段。

## 有出处的尺寸（引用，不要扩写）

下列数字在 2026-11-17 核对过对应页面。例外和上下文以原页为准，这里不复制整节。

| 用途 | 数字 | 出处 |
|------|------|------|
| iOS / iPadOS 按钮热区的一般规则 | 至少 44×44 pt | Apple HIG Buttons |
| iOS / iPadOS 控件 | 默认 44×44 pt，最小 28×28 pt | Apple HIG Accessibility |
| macOS 控件 | 默认 28×28 pt，最小 20×20 pt | 同上 |
| iOS / iPadOS 自定义文字 | 默认 17 pt，最小 11 pt | 同上 |
| macOS 自定义文字 | 默认 13 pt，最小 10 pt | 同上 |
| Android 可交互目标 | 至少 48×48 dp；视觉更小的控件要靠内边距补足目标，并避免目标重叠 | Android Accessibility Help；Jetpack Compose Material 3 的最小交互尺寸 |
| 网页指针目标 | WCAG 2.2 AA：至少 24×24 CSS 像素，另有间距等例外；AAA：至少 44×44 CSS 像素，例外更少 | W3C WCAG 2.2 |
| 网页正文对比 | WCAG 2.2 AA：普通文字至少 4.5:1，大号文字至少 3:1 | 同上 |

Windows 本轮没有找到一条可以当成「最小点击像素」来引用的官方数字，所以不写。桌面 Windows 跟随 WinUI 控件的尺寸，键盘和指针路径都要在。

Apple 还写到：有边框的控件周围大约 12 pt、没有边框的大约 24 pt，能降低误触。这是 HIG 的经验说法，不是本仓库另定的网格。

## 输入和窗口

- **触控**：主操作放在拇指或手容易够到的一边，目标用上表里该平台的尺寸。相邻目标留出空隙。
- **指针和键盘**：桌面和网页的主任务不能只放在悬停里。焦点要看得见。高频命令可以有快捷键，但快捷键不是唯一入口。macOS 的完整命令进菜单栏；Windows 的命令进命令栏、菜单或上下文菜单；网页的命令留在页面里，不假装拥有系统菜单栏。
- **响应式窗口**：窄了就重排，而不是把手机画面放大。阅读用的正文限制行长。宽窗口把导航固定下来，把主内容让出来。
- **系统 chrome**：状态栏、标题栏、菜单栏、浏览器工具栏不属于应用内容。网页草稿可以画出浏览器栏，用来表明「这是网站」；原生草稿画出该系统的窗口栏。不要两套一起画在同一个窗口里冒充一种应用。
- **无障碍**：文字能放大时布局仍成立；不只用颜色；图片按钮有文字标签或可访问名称。权限、空、加载、错误、离线按任务需要覆盖。某项确实没有（例如纯本地计算没有加载），写「不适用」和原因。

## 和极简的边界

简洁是去掉不服务主任务的摩擦，不是把功能藏起来。高频保留在一级；中频进二级；低频进设置；危险操作分开，并提供撤销或确认。藏进一个菜单又称为简洁，是反模式。

GNOME 的指南更倾向让破坏性操作可以撤销，而不是一律先弹确认。Apple 的 Agency 则要求破坏性操作先确认。目标是 GNOME 时，把这个张力写进取舍，不要无声地套用 iOS 确认框。KDE 要求常见路径在默认界面里看得见，专家快捷键是加速，不是唯一入口。
