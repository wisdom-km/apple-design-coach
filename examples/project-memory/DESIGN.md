## Color roles

- 背景：#f4f7f5（项目决定）
- 主文字：#1a1c1b（项目决定）
- 次文字：#5c6560（项目决定）

- 危险：#8c1d18 的文字色，不使用主操作的填充

## Type

- 系统无衬线。不嵌入专有字体
- 主结果（例如一个月的结余）是唯一的大字，示例里约 32px
- 正文约 16px。行内金额与正文同级，字重更重，等宽数字，右齐。它不是第二处海报数字
- 次要说明更小、更淡
- 中文不用强负字距

## Density

- 单任务，无 3–5 项目的地底栏
- 行列表，不做等权卡片

## Components

- 顶栏标题 + 溢出菜单里的设置
- 主按钮「保存」
- 「删除」与主按钮不同形

## Placement

- 设置不占主路径。顶栏的「更多」要看得出里面是分类或货币，尤其在空白和失败里
- 长标题不能只剩省略号。列表行可以最多两行，同一句全文留在详情里
