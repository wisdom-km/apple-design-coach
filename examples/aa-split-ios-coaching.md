## 测试输入（模拟用户）

**表面：** iOS

**需求：**
- 为谁：和朋友外出吃饭后，想快速算「每人付多少」的人
- 问题：系统计算器要自己记总额/人数/小费，容易算错；现有草稿 App 把所有旋钮堆在一屏，像工程面板
- 成功：打开后 30 秒内得到「每人应付」；能改人数/小费后立刻重算；可把结果复制出去发群
- 约束：离线可用；不要账号；不要通讯录；不要强制引导页

## 教练输出（按 skill 六段骨架）

# 设计合同（Design Contract）

- **表面：** iOS
- **一句话目的（Purpose）：** 让聚餐后的人在离线状态下，用最少步骤得到「每人应付多少」，并方便把数字发到聊天里。
- **核心用户与情境：** 饭局结束、人还在桌边或刚结完账；时间紧、可能微醺、不想开脑内算术。
- **成功标准：** 默认路径 ≤ 3 次有意义操作即可看到人均；改人数/小费结果即时更新；一键复制「人均 ¥X（共 N 人）」文案。
- **非目标（刻意不做）：** 账号/社交网络；OCR 读账单相册；税率/服务费专业会计；长期账单历史；iCloud 同步；人均权重复杂分账（v1 不做）。
- **原则取舍摘要：**
  - **Purpose > 功能完整感**：草稿里的税率/权重/iCloud/相册全部砍掉或延后——它们稀释主目的。
  - **Simplicity ≠ 藏起来**：不把「小费」塞进设置；小费是主路径一部分，但用分段控件降低复杂度。
  - **Agency**：人数步进可撤销（改回即可）；无强制 wizard。
  - **Responsibility**：不申请相册/通讯录；无开屏权限。
  - **Familiarity**：单屏工具型 App，参考系统计算器的「内容即界面」，但结果区永远可见（避免按完才跳页）。

# 功能落位 / 信息架构（Placement & IA）

- **主导航 / 入口：** **无 Tab**。这是单任务工具：启动即主屏。设置用导航栏尾部齿轮进入二级（仅货币符号、小数取整规则）。
- **主任务路径：**
  1. 打开 App → 焦点可在「总额」
  2. 输入总额（数字键盘）
  3. 调人数（步进器，默认 2）
  4.（可选）设小费：关 / 百分比 / 固定额
  5. 阅读「每人应付」大数字 → 点「复制结果」
- **次要功能与设置落点：**
  - 小费：主屏中段（高频）
  - 货币符号、取整规则：设置页（低频）
  - 「不均分 / 按人改额」：v1 不做；若用户坚持，v1.1 用 Sheet「调整某人」而非主屏表格
- **跨表面差异：** 本次仅 iOS。若将来做浏览器扩展：popup 只保留总额+人数+人均+复制；小费进 Options（小表面 Familiarity）。

# UI 结构

- **屏幕清单：**
  1. **主屏 SplitNow** — 输入与结果同屏
  2. **设置**（Push）— 货币、取整
  3. （可选）**复制成功** — 轻量 HUD/Toast，非新页
- **区域层级：**
  - **主内容上：** 总额输入（最大触控、最醒目）
  - **主内容中：** 人数步进 + 小费分段
  - **主内容下（锚定）：** 「每人」超大结果 + 次行「合计 / 小费」说明
  - **Chrome：** 导航标题「AA」；尾部设置
  - **主 CTA：** 「复制结果」（结果为 0 时禁用）
- **控件与文案原则：** 系统数字键盘；人数用 stepper；小费用分段「无 / % / 额」；文案用「每人应付」而非「计算结果」；避免「开始计算」按钮——**输入即计算**（减少一步，符合 Simplicity）。
- **线框级结构示意（重新设计后）：**

```
┌─────────────────────────────┐
│ AA                    [设置] │
├─────────────────────────────┤
│ 总额                         │
│ ┌─────────────────────────┐ │
│ │            328.00   CNY │ │  ← 主输入
│ └─────────────────────────┘ │
│                             │
│ 人数     [ − ]  4  [ + ]    │
│                             │
│ 小费     ( 无 | 10% | 额 )  │
│          （选%时出现滑杆/预设）│
│                             │
│ ─────────────────────────── │
│ 每人应付                     │
│        ¥ 90.20              │  ← 最大字号
│ 含小费 ¥36 · 共 4 人         │
│                             │
│      [  复制结果  ]          │
└─────────────────────────────┘
```

# 状态与权限

- **空：** 总额为空 → 结果区显示「输入总额」占位，CTA 禁用
- **加载：** 无网络请求；无加载态
- **错误：** 非数字/超额小数 → 行内提示「请输入有效金额」；不弹系统 Alert 打断
- **成功：** 复制后 Toast「已复制」
- **离线：** 默认即离线，无需提示
- **权限：** **不请求任何敏感权限**。拒绝路径不适用。
- **可撤销：** 改人数/小费即时重算；无「提交」锁死；设置内改取整立即影响主屏（返回即见）

# 参考建议

- **系统模式：** iOS 单屏实用工具（内容优先）；`UIStepper` 调离散数量；分段控件切换小费模式；导航栏进入设置；结果用大动态字体保证可读（Flexibility/a11y）
- **参考图方向：** 上图 ASCII 已足够；若出图只需一张竖屏线框，标注「总额区 / 参数区 / 结果锚定区 / CTA」，不要精修材质
- **Craft / Delight（克制）：** 数字变化时轻微字重/模糊过渡；复制成功用系统触感轻敲——不要彩带

# 风险与翻译备注

- **意图 vs 线框现实：** 用户草稿把税率、权重表、iCloud、相册堆进主屏 → 教练按 Purpose 砍掉；若产品坚持「不均分」，应进 Sheet，不回主屏表格
- **反模式已拦截：** 开屏权限、假完整感、为极简把小费藏进汉堡、用「开始计算」制造多余一步
- **假设：** 默认货币 CNY、默认人数 2、默认小费关；可在设置改
- **开放问题：** 是否需要「最近一次总额」本地记忆？建议 v1 可做无感本地草稿，但不要做完整历史列表
